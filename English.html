7句公式卡 · Formula Cards

考試閱讀同寫作全部都係用呢 7 句
1

There is / There are 有…

There is a… / There are…

2

It is on the __ floor 喺…樓

It is on the second floor.

3

We can + 原形 可以…

We can take photos.

4

We cannot / We must not + 原形 唔可以…

We must not draw.

5

We must + 原形 一定要…

We must keep quiet.

6

We like + verb-ing 鍾意做…

We like looking at pictures.

7

問句 → 完整句子答 Answer in a full sentence

Where is…? → It is on the…

記住：原形 = 動詞最原始樣，唔加 -s / -ing / -ed。verb-ing = 動詞 + ing。

5個決定樹 · Decision Trees

考試嗰陣跟住行就唔會揀錯

TREE 1

Can 定 Like？

can → 原形　·　like → verb-ing

TREE 2

There is 定 There are？

1 → There is a…　·　2+ → There are…

TREE 3

Must 定 Must not？

✓ → Must　·　✗ → Must not　·　之後原形

TREE 4

Plural 點變？

不規則先，再睇字尾

TREE 5

Go 定 Goes？

一個 → goes / is　·　一堆 → go / are

HOW TO USE

先問自己：呢題係邊個決定樹？
跟箭咀行一步，唔好憑感覺。
